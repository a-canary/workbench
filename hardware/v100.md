# Tesla V100 32GB

## Key facts
- Compute capability: sm_70
- Memory: 32GB HBM2
- Bandwidth: ~900 GB/s
- CUDA toolkit: 12.8 (rootless build)

## Build notes
- Use `--cuda-architecture=all-major` or pin `sm_70`
- Rootless CUDA build avoids system-wide driver conflicts
- See `agents-pub/plans/v100-qwen-mtp` for build/bench scripts

## Model fit
- Qwen3.8-27B Q6_K: ~22GB weights + ~4.5GB KV (q8_0) @131k = ~26.5GB total (fits)
- Decode ceiling: ~40 tok/s (bandwidth-bound at 900 GB/s for 22GB weights)
